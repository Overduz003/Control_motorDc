# Control_motorDc

**Objective**
Implement a proportional (P) controller to control the angular position of a motor and evaluate its performance using different reference signals.

<img width="922" height="823" alt="image" src="https://github.com/user-attachments/assets/aed685aa-65df-4236-9606-6f16e0702ae0" />


**Parte 1**

El problema consiste en desarrollar un sistema de control capaz de desplazar un motor DC desde su posición inicial de 0 grados hasta un ángulo objetivo de 45 grados utilizando la realimentación de un sensor de posición y un puente H, asegurando que, una vez alcanzado el objetivo, el motor invierta su giro para regresar de manera controlada y precisa a la posición de 0 grados.

https://github.com/user-attachments/assets/ba6e1193-ecfe-42d5-b8f7-d6b2213b5402

**Parte 2**

esta segunda parte consiste en incorporar temporizadores de tres segundos antes de cada cambio de posición: el sistema debe mantener el motor en reposo a 0 grados durante tres segundos antes de ejecutar el desplazamiento hacia los 45 grados, y una vez alcanzado este ángulo, mantenerlo estacionario otros tres segundos más antes de ordenar el retorno controlado a la posición inicial.
